# Illustration sources

`cultures.png` is a generated schematic of cultured cells. The blue and orange dishes distinguish the control input from the treated-expression target. This is a schematic illustration, not microscopy or evidence of a change in cell appearance.

`caffeine.json` contains atom labels, bonds and RDKit-generated two-dimensional coordinates for caffeine (`Cn1c(=O)c2c(ncn2C)n(C)c1=O`). Caffeine is an example of a molecular input; the benchmark contains many compounds. Its structure is drawn as vector lines and text.

The expression grids and gene-value vectors describe data organization. The control-averaging colors are illustrative and are averaged column by column. Numerical result plots are generated from the project result tables.
